Panduan Setup Layanan Eksternal

Dokumen teknis untuk client — berisi langkah daftar dan konfigurasi RajaOngkir, Midtrans, dan Resend, ditambah setup cron job Hostinger agar toko online berjalan penuh.

1. RajaOngkir Cek Ongkir

Paket yang direkomendasikan
Starter — Gratis. Cukup untuk toko kecil: 100 hit "Cek Ongkir" per hari. Upgrade ke Pro (Rp 149.000/bulan) hanya jika pesanan sudah ratusan per hari. Paket Enterprise tidak perlu — fitur ekstranya (buat resi, pickup otomatis) untuk logistik besar.

Cara Daftar

  1. Buka rajaongkir.com → klik Daftar Sekarang di paket Starter
  2. Isi: nama lengkap, email aktif, nomor HP, nama toko
  3. Verifikasi email
  4. Masuk dashboard → menu API Key → copy API Key

Konfigurasi Server

Isi di file .env server (Hostinger):

RAJAONGKIR_API_KEY=isi_api_key_kamu_di_sini

2. Midtrans Pembayaran Online

Metode yang Direkomendasikan

MetodeBiayaKeterangan
Bank Transfer (Virtual Account) Rp 4.000 / transaksi BCA, BNI, BRI, Mandiri — paling umum di Indonesia
QRIS 0,7% / transaksi Satu QR untuk GoPay, ShopeePay, Dana, OVO, dll
Kenapa keduanya?
Bank Transfer untuk customer yang lebih nyaman transfer bank. QRIS untuk yang pakai e-wallet. Keduanya cover hampir semua segmen pembeli. GoPay/ShopeePay langsung bisa diaktifkan nanti (biaya 2%), tapi QRIS sudah bisa terima keduanya — tidak wajib dari awal.

Cara Daftar

  1. Buka dashboard.midtrans.com → klik Sign Up
  2. Isi data bisnis: nama lengkap pemilik, email aktif, nomor HP, nama toko
  3. Verifikasi email → masuk dashboard

Aktivasi Akun (KYC)

Untuk menerima pembayaran nyata (bukan sandbox), Midtrans memerlukan dokumen:

  • KTP pemilik
  • NPWP — tidak wajib untuk perseorangan
  • Nomor rekening bank untuk pencairan dana
  • Dokumen legalitas — bisa pakai NIB dari OSS kalau ada

Proses verifikasi biasanya 1–3 hari kerja.

Cara Ambil API Key

  1. Dashboard Midtrans → Settings → Access Keys
  2. Ada dua mode: Sandbox (testing) dan Production (live, uang nyata)
  3. Copy Server Key dan Client Key
Mulai dari Sandbox
Gunakan Sandbox key dulu saat pertama setup. Setelah semua tes berhasil, baru ganti ke Production key dengan mengubah MIDTRANS_IS_PRODUCTION=true.

Konfigurasi Server

MIDTRANS_SERVER_KEY=isi_server_key_kamu
MIDTRANS_CLIENT_KEY=isi_client_key_kamu
MIDTRANS_IS_PRODUCTION=false   # ganti true kalau sudah siap live

Testing Pembayaran (Sandbox)

  • VA BCA sandbox: bayar berapa saja → otomatis sukses
  • Kartu test Visa: 4811 1111 1111 1114, CVV: 123, expired: tanggal apa saja di masa depan

3. Resend Email Notifikasi

Resend mengirim email ke admin setiap ada pesanan baru yang dibayar. Gratis sampai 3.000 email/bulan — lebih dari cukup untuk toko kecil.

Cara Daftar

  1. Buka resend.com → klik Sign Up (gratis)
  2. Verifikasi email
  3. Masuk dashboard

Verifikasi Domain (wajib)

Email hanya bisa dikirim dari domain yang sudah diverifikasi. Contoh: noreply@drplant.id

  1. Dashboard Resend → menu Domains → Add Domain
  2. Masukkan domain: drplant.id
  3. Resend berikan beberapa record DNS (DKIM, SPF)
  4. Tambahkan record DNS tersebut di panel domain (Niagahoster, Cloudflare, dll)
  5. Klik Verify → tunggu status hijau (5–30 menit)

Cara Ambil API Key

Dashboard Resend → menu API Keys → Create API Key → copy

Konfigurasi Server

RESEND_API_KEY=isi_api_key_resend_kamu
MAIL_MAILER=resend
MAIL_FROM_ADDRESS="noreply@drplant.id"   # domain yang sudah diverifikasi
MAIL_FROM_NAME="Doctor Plant Indonesia"

4. Cron Job Hostinger Pesanan Expired Otomatis

Sistem secara otomatis mengexpire pesanan yang tidak dibayar dalam 24 jam dan mengembalikan stok. Ini butuh satu setting cron job di Hostinger.

  1. Login Hostinger → hPanel → Advanced → Cron Jobs
  2. Klik New Cron Job
  3. Pilih interval: Every minute (atau custom * * * * *)
  4. Isi command — sesuaikan path ke folder Laravel: 
    cd /home/username/public_html/api && php artisan schedule:run >> /dev/null 2>&1
    Ganti username dan path sesuai akun Hostinger.
  5. Klik Simpan
Penting
Tanpa cron job ini, pesanan tidak akan expired otomatis meskipun sudah melewati 24 jam.
